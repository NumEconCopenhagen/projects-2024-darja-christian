# Data analysis project

Our project is titled **Annual GDP Growth and Debt of the 27 EU-countries**.

The **results** of the project can be seen from running [DC_dataproject.ipynb](DC_dataproject.ipynb).

We apply the **following datasets**:

1. gdp_growth_world_bank_update.xlsx (*https://databank.worldbank.org/reports.aspx?source=2&series=NY.GDP.MKTP.KD.ZG&country=#*) 
1. new_debt_data.xlsx (*https://www.statbank.dk/20172*)

**Dependencies:** Apart from a standard Anaconda Python 3 installation, the project requires the packages listed in  [DC_dataproject.ipynb](DC_dataproject.ipynb).
