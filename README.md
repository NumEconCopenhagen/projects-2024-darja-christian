This repository contains  
1. Inaugural project. Here we solve some "basic" economic problems.
2. Data project. We fetch data from  the World Bank (*https://databank.worldbank.org/reports.aspx?source=2&series=NY.GDP.MKTP.KD.ZG&country=#*) and from Danmarks Statistics (*https://www.statbank.dk/20172*) and show that the relationship between annual debt and annual GDP growth over 20 years for the 27 EU-countries.
3. Model project. We model the Stackelberg-Duopol. We extend the basic model duopol to an oligopol by adding a third firm to the market. We can show how the optimal solution changes depending on the parameters of the model and depending on the order of production.
