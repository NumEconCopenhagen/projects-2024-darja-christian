This repository contains  
1. Inaugural project: Here we solve some "basic" economic problems and present the solutions.
2. Data project: We fetch data from  the World Bank (*https://databank.worldbank.org/reports.aspx?source=2&series=NY.GDP.MKTP.KD.ZG&country=#*) and from Danmarks Statistik (*https://www.statbank.dk/20172*). We present the relationship between annual debt (in €) and annual GDP growth (in %) for the 27 EU-countries over 20 years.
3. Model project: We model the Stackelberg-Duopol. We solve the model numerically and analytically. We extend the basic duopol to an oligopol by adding a third firm to the market. We can show how the optimal solution changes depending on the parameters of the model and depending on the order of production.
4. Exam project: We solve the different task given in the exam and present the results.
