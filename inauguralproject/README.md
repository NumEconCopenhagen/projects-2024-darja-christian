# Inaugural project

The **results** of the project can be seen from running [DC_inauguralproject.ipynb](DC_inauguralproject.ipynb). The project deals with solving some basic economic problems in Python. The economic problems are pre-specified. We solve some by numerical optimization using a solver. We will also plot some of our results to compare graphically different results when changing some restrictions.  

**Dependencies:** Apart from a standard Anaconda Python 3 installation, the project requires no further packages than listed in [DC_inauguralproject.ipynb](DC_inauguralproject.ipynb).
