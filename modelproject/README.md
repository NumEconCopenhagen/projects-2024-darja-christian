# Model analysis project

Our project is titled **Stackelberg Duopol**. We start with a basic duopol market where one firm is the leading firm and produces first. Then the second firm oberves how much the leader produced and produces after him. Later, we extend the market to consider three firms. We will solve the models analytically as well as numerically. 
Our project has the following parts: 
- Analytical solution
- Numerical solution
- Graphical analysis 
- Extension from a duopol to an oligopol
- Conclusion


The **results** of the project can be seen from running [modelproject.ipynb](modelproject.ipynb).

**Dependencies:** Apart from a standard Anaconda Python 3 installation, the project requires no further packages than listed in [modelproject.ipynb](modelproject.ipynb).
